# Scout Sources

The watch list per department. EDIT THIS to your own departments and sources. Each scout web-searches these plus the open web for its domain. The four below are a starting point for a software / AI operator. Swap them for whatever fields you need to stay current in.

## technology
- New MCP servers and registries
- The frameworks and platforms in your stack (their changelogs and release notes)
- Dev-productivity and agent-infra tools (eval tooling, observability, durable execution)

## llms-models
- Model releases, pricing changes, capability shifts from the providers you use
- Agent SDK and CLI release notes
- Self-hostable / open-weight models relevant to your privacy or cost needs
- Agent memory and RAG advances

## design
- Component libraries and design-system tooling in your stack
- Design tools and code-to-design updates
- Motion and graphics libraries
- Filter HARD for your aesthetic; reject generic-template output

## operations-growth
- Proposal, e-sign, billing, and payment tooling
- Outbound, enrichment, and CRM tools (with your compliance constraints)
- SEO / GEO / AI-visibility tooling
- Content distribution and automation

> Tip: keep each department to 4-6 sources. The scout also searches the open web, so the list is a steer, not a cage.
